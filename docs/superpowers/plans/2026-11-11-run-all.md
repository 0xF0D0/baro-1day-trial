# Run-All Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command, `python part1/run.py`, that runs the collectors side by side, loads their files, labels new ad texts and applies the labels.

**Architecture:** `run.py` is an orchestrator with no logic about sources or tables: it plans jobs from the collector folders, runs them as child processes with a bounded pool and a timeout, summarises the run result files they wrote, then starts the existing loader and label commands as processes. Everything it starts is a command line, so tests swap in stub scripts.

**Tech Stack:** Python 3 standard library only (`subprocess`, `concurrent.futures` or polling, `fcntl`, `signal`, `argparse`). `unittest`, no database, no network.

**Spec:** `docs/superpowers/specs/2026-11-11-run-all-design.md` (binding).

## Global Constraints

1. Hand-written code. At least one source is collected without a paid scraping service.
2. Rerun-safe. Running twice creates no duplicates. A missing item is marked ended, never deleted.
3. Honest gaps. A source that could not be reached is recorded as "could not look", never as "nothing found". Partial collection is marked.
4. Clean collection. No one else's account. No personal data of private individuals. Requests are spaced: never two requests at once to the same source site.
5. Local Postgres, one command, reproducible by someone else.
6. Nothing under `part1/collectors/` or `part1/pipeline/` is changed.
7. `run.py` never prints or logs a token or a key, and never reads `.env`.
8. Documents and code comments are in English. No absolute local paths in any committed file.
9. Tests run with `.venv/bin/python -m unittest discover -s part1/tests` from the repository root, use only stub scripts in temporary directories, and finish in under a minute. The existing suite (`part1/pipeline/tests`) stays green.

## Review Focus

1. A collector that hangs is stopped together with the processes it started, and the pass goes on (Task 1).
2. Two passes at once: the second one exits 3 and starts nothing (Task 1).
3. A collector that crashes does not keep the others' files from being loaded, and the exit code says something failed (Task 1).
4. A collector folder that is not in `BRAND_PARALLEL` never gets more than one job (Task 1).
5. A wrong `--brand` or `--sources` stops before anything runs (Task 1).

```python
ROOT = Path(__file__).resolve().parents[1]          # the repository root

@dataclass(frozen=True)
class Job:
    folder: str
    brand: str | None                                # None means --all

def collector_folders(collectors_dir: Path) -> list[str]     # folders holding source_collector.py, by name
def read_brands(collectors_dir: Path) -> list[str]            # slugs of brands.json, in file order
def select_sources(folders: list[str], sources: str | None) -> list[str]   # ValueError("unknown source: <entry>")
def plan_jobs(folders: list[str], brands: list[str], brand: str | None) -> list[Job]
def run_jobs(jobs: list[Job], collectors_dir: Path, log_dir: Path, max_jobs: int, timeout_s: float,
             python: str = sys.executable, on_done=None) -> dict[Job, str]
    # value: the exit code as text ("0", "1", ...), "timeout" or "not_started";
    # on_done(job, exit_text, seconds) is called as each job ends
def summarize(collectors_dir: Path, folders: list[str], start_stamp: str) -> dict
    # {"runs": n, "ok": n, "partial": n, "could_not_look": n, "cost_usd": float}
def main(argv: list[str] | None = None, *, load_cmd: list[str] | None = None, label_cmd: list[str] | None = None,
         labels_file: Path | None = None, state_dir: Path | None = None) -> int
```

- `main`'s keyword arguments exist for the tests. Defaults: `load_cmd = [sys.executable, str(ROOT / "part1/pipeline/load.py")]` (`main` appends `--collectors-dir <dir>`), `label_cmd = [sys.executable, str(ROOT / "part1/pipeline/angles.py"), "--label"]`, `labels_file = ROOT / "part1/pipeline/labels/ad_angles.jsonl"`, `state_dir = ROOT / "part1"` (holds `.run.lock` and `logs/`).
- `--timeout` is in minutes and may be fractional (tests use `0.02`).
- `select_sources`: entries are split on commas and stripped; an entry of digits matches the folder whose leading number equals it as an integer (`1` matches `01_google_ads_transparency`); any other entry must equal a folder name; the result keeps folder order and has no duplicates; `None` selects all.
- Output lines, exactly as in spec section 2: `collect <folder> <brand or all> exit=<text> <seconds>s` with whole seconds; `collect: jobs=<n> failed=<n> runs=<n> ok=<n> partial=<n> could_not_look=<n> cost_usd=<%.4f>`; `run: another run is in progress`; `run: interrupted`; `unknown brand: <slug>`; `unknown source: <entry>`.
- The pass's start stamp is taken once, in UTC, as `YYYYMMDDTHHMMSSZ`, before the first job starts; it names the log folder and is the lower bound of the summary.
- Child processes are started with `start_new_session=True`, stdout and stderr to the job's log file, stdin from `/dev/null`, the working directory left as it is. The load and label commands inherit the terminal's output (their lines appear as they print them).
